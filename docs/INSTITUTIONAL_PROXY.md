# 기관성 매수 프록시

Toss Open API에는 종목별 기관 순매수 데이터가 없으므로, 시스템은 실제 기관 수급으로 표시하지 않고 `institutional_proxy` 점수로만 기록한다.

진입 시 다음 네 항목을 평가한다.

- 거래량 급증: 최근 1분 거래량이 기존 기준 이상
- VWAP 상회: 현재 가격이 최근 VWAP 위
- 매수호가 우위: 상위 5호가의 매수 잔량 우위
- 지속성: 완료된 최근 3개 봉이 각 직전 구간 VWAP 위에서 유지

기본 진입 기준은 4개 중 3개 이상이다. 점수는 기관의 실제 주문이나 투자자 유형을 의미하지 않으며, 주문 체결 데이터가 추가되기 전까지의 보수적인 시장 미시구조 대체 지표다.

설정:

- `INSTITUTIONAL_PROXY_FILTER=true`
- `MIN_ORDERBOOK_IMBALANCE_RATE=0.10`
- `MIN_INSTITUTIONAL_PROXY_SCORE=3`

운영 전환 후에는 진입 로그의 `proxy=점수/4`를 기록하고, 장 마감 후 실제 공개 수급 데이터와 비교해 기준을 재평가한다.
